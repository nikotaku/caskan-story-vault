# エスたま自動化

キャスカンを正として、Browserbase上のエステ魂管理画面へ次の処理を行う。

- セラピスト新規追加時のプロフィール・写真登録
- 登録済みセラピストのパネル写真・紹介文・プロフィール項目の変更時に自動同期
- O2の登録メールアドレスと共通パスワードを使った魂セラピスト発行・初回ログイン設定
- 承認済みシフトの追加・変更・削除を即時同期
- 毎日 03:10（JST）に公開出勤表を取得し、向こう7日分を再同期

## 初回設定

Vercelの Production / Preview / Development に以下のサーバー専用環境変数を設定する。

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`（推奨。VercelのSupabase連携が自動設定）
  または `SUPABASE_SERVICE_ROLE_KEY`（旧形式）
- `BROWSERBASE_API_KEY`
- `BROWSERBASE_PROJECT_ID`
- `CRON_SECRET`

秘密値はGitやチャットへ貼らない。設定後に再デプロイし、キャスト管理の「エスたま自動化」から「エステ魂へログイン」を開く。ライブブラウザ内で店舗管理アカウントへログイン後、「ログイン完了を確認」を押す。

## 運用

プロフィール変更は管理画面からの保存直後に同期し、通信失敗や別経路からの更新も1分ごとの再試行で回収する。失敗した処理は指数バックオフで最大5回再試行する。ログイン期限切れ時はジョブを保持したまま `waiting_for_login` にし、再ログイン後に「待機中の自動処理を今すぐ実行」で再開できる。

BrowserbaseのContext IDだけをDBに保持する。Browserbase APIキーとエステ魂の店舗パスワードはDBに保存しない。魂セラピストの初回設定にはO2の登録メールアドレスと、管理画面に再表示しない認証情報テーブルへ保存したO2のパスワードを利用する。
